# ChangeProof

Experimental open-source CLI for comparing JSON API snapshots and flagging potentially breaking structural changes.

The complete v0.6 prototype is being prepared for publication. This repository is not yet a verified release.

## Status

- 31 local unit tests passed on the v0.6 source package.
- Live HTTPS integration: pending.
- GitHub Actions: pending.
- API compatibility judgments are heuristic, not guarantees.

Do not commit API credentials or private response snapshots.
